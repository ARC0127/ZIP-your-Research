# How to Use ZYR v1.6.5

This directory contains the concise operational guides for the current ZYR package.

## Current guides

- `ZYR_ENGINE_BINDING_HOW_TO_USE_v1.6.5.md`: the canonical engine-binding guide.
- `PLATFORM_SKILLS_integr_v1.6.5.md`: platform artifact workflows for DOCX / PDF / spreadsheet delivery.

## Core routing rule

```text
research idea / method / storyline → proof_engine
visible writing → writing_engine
figure-making → figure_engine
code / repository repair → coding_engine
release validation → S650
```

Older how-to files that described obsolete package layouts are intentionally not part of this release.
