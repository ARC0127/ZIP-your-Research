## Core routing rule

```text
local research question → relevant atomic research skill
proof obligation → proof_engine
local prose → S603; integrated manuscript → writing_engine
publication figure → figure_engine when its backend is available
research code → coding_engine
integrated research package → S650; repository packaging → docs/RELEASE.md
```

Older how-to files that described obsolete package layouts are intentionally not part of this release.
