# Integrated Logic Reconstruction Report v1.0

## Integration objective
The goal is not directory concatenation. The three external repositories are restructured into ZYR's operating model:

- ZYR remains the state machine, truthfulness layer, evidence layer, and routing authority.
- Research-Paper-Writing-Skills becomes section architecture and reviewer-facing paper construction.
- awesome-ai-research-writing becomes bilingual rewrite, prompt-operation, experiment analysis, and caption-generation tactics.
- figures4papers becomes figure design theory, Matplotlib implementation conventions, and visual claim/caption verification.

## Why S6xx
ZYR already uses S2xx for research core, S3xx for experiments, S4xx for reproducibility, and S5xx for paper operations. The integrated sources are broader than one existing S5xx paper operation, so they are assigned S6xx:

- S601-S604: manuscript writing and result narration.
- S621-S623: publication figure operations.

## Route-level logic
The integrated stack never bypasses ZYR. For example:

- Rewriting a paragraph: Mode Lock → evidence gate → S603 → verify no new claims.
- Reviewing a paper: Mode Lock → S203/S226/S229 → S602 → S503.
- Building a figure: Mode Lock → claim/evidence mapping → S621 → S622 → S512/S517.
- Writing results: Mode Lock → S303/S304/S311 → S604 → figure/table audit.

## Content preservation
All source repositories are retained verbatim under `ext/src/`. This means examples, scripts, images, and metadata remain available, while the S6xx files provide a ZYR-native operational layer.

## Conflict handling
External skill advice is lower priority than:
1. ZYR state machine and Mode Lock.
2. ZYR global guardrails.
3. User explicit instruction.
4. Tool/file truth.
5. External source heuristics.

## Known limitation
The integration reads and incorporates text rules, script conventions, and repository structure. Binary images are preserved and referenced; they are not rewritten into textual skills except through the figure design rules and demo-script mapping.
